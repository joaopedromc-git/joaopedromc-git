## 💼 Experiência e conhecimentos

* **IA aplicada:** agentes do Claude Code com regras e memória, geração de vídeo (Veo), narração (edge-tts), edição de vídeo em código (HyperFrames e Remotion) e revisão automática com saída em JSON Schema
* **Automação de processos:** fluxos automatizados com n8n
* **Integração de dados:** HubSpot, APIs REST, webhooks, PostgreSQL e sistemas externos
* **Business Intelligence:** dashboards, KPIs, filtros e visualização de dados com Metabase
* **Back-end:** APIs e aplicações em C# e .NET, Next.js e FastAPI
* **Banco de dados:** consultas, views, agregações, modelagem e indicadores de desempenho
* **Infraestrutura:** VPS Linux, Docker, Traefik, Nginx, SSL, proxy reverso, backups e publicação de aplicações
* **Pipelines de dados:** extração, transformação, sincronização e visualização automáticas de dados do negócio
* **Versionamento:** Git, GitHub e verificação automática com GitHub Actions
